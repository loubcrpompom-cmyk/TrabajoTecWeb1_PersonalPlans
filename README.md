# TrabajoTecWeb1_PersonalPlans
Un sistema compuesto por una API REST y una aplicación web que recomienda un plan de actividades en función de tres criterios: 
- presupuesto (en bolivianos)
- tiempo disponible (en horas)
- compañía
Objetivos a completar:
• Implementar la API con una arquitectura en tres capas (Core, Infrastructure y Api) en C# sobre ASP.NET Core, con persistencia en una base de datos relacional mediante Entity Framework Core. 
• Implementar la autenticación con tokens JWT y el control de acceso por roles (Usuario y Administrador) en el 100 % de los endpoints protegidos. 
• Desarrollar un motor de recomendación que combine de 1 a 3 actividades del catálogo respetando el presupuesto, el tiempo y la compañía indicados por el usuario. 
• Implementar la gestión del catálogo de actividades, los favoritos, el historial y las calificaciones, y validar las reglas de negocio mediante pruebas unitarias y una colección de pruebas en Postman antes de la evaluación final.
